# Cookies by Maites — אפיון (מאושר מול הבעלים, 2026-11-16)

שינוי בהחלטה — רק אחרי שאלה, ולעדכן כאן.

## בסיס
- **אנדרואיד בלבד**, Kotlin + Jetpack Compose. מזהה חבילה: `com.maites.cookies`.
- הפצה: APK חתום ב-GitHub Releases + "בדוק עדכונים" בהגדרות.
- **Firebase**: התחברות גוגל, Firestore (offline-first), **Storage לתמונות** (תוכנית Blaze + התראת תקציב $1).
- עברית מלאה, RTL.

## שפת עיצוב (עודכן 2026-11-16 — לא העתק של noted)
- כיוון: דומה ל-Payments-2026 אבל זהות משלה. **Rubik** בלבד. רקע `#F6F5F1`, כרטיסים לבנים רדיוס 24–26, צל רך.
- **סטיקר**: כפתור ראשי עם קו מתאר דיו + צל קשה; אייקונים צבעוניים שטוחים עם קו מתאר. accent ברירת מחדל קרמל `#F08A24` (+ פיסטוק / פטל / אוכמניות). בהיר + כהה.
- **רק רכיבי אפליקציה**: סרגל תחתון עם `+` מורם, דפים שנדחפים (החלקה מהקצה לחזרה), גיליונות תחתונים, מקלדת מספרים משלנו לסכומים, segmented, מתגים, צ'יפים, טוסטים. אין קישורים/רכיבי ווב. כל אלמנט מעוצב.
- ניווט: **מתכונים · מוצרים · + · קניות · הגדרות**.
- תמונות: מתכון = כרטיס עם תמונה ריבועית גדולה, דף מתכון עם hero מלא + גלריה; מוצר = תמונת אריזה על לבן.
- תנועה: transform/opacity בלבד, קפיץ ניתן לעצירה בדפים ובגיליונות, מספרים "נספרים" למקום.

## ביצועים ותמונות
- תמונות מוצרים לפי ברקוד מ-**Open Food Facts** (חינמי). נמשכות **פעם אחת** ב-GitHub Action, מוקטנות ל-webp ‏~200px (2–7KB), נשמרות ב-Firebase Storage. באפליקציה: Coil עם מטמון דיסק, טעינה עצלה. מוצר בלי תמונה טובה — אייקון קטגוריה.
- תמונות מתכון מוקטנות במכשיר לפני העלאה (~1280px webp) + thumbnail קטן לרשימות.
- מחירים: רק מוצרים שברשימה, מסונכרן פעם ביום; האפליקציה קוראת מהמטמון המקומי (Room) — אין המתנה לרשת.

## מתכונים
- כרטיס מתכון: תמונה ראשית + גלריה (החלקה), קטגוריה, הערות.
- מרכיבים מקושרים למוצרים (מחיר נמשך מהמוצר) + אייקון לכל מרכיב.
- **משחק בכמויות**: שינוי תפוקה (מספר יחידות/מנות) או מכפיל → כל הכמויות והתמחיר מתעדכנים חי.
- **תמחיר**:
  - עלות מרכיבים (לפי המחיר הנבחר של כל מוצר: הזול בעיר / רשת מועדפת / ידני).
  - **עלויות נוספות**: אריזה, גז/חשמל, עבודה — סכום קבוע או אחוז.
  - **עלות ליחידה** (למשל לעוגייה).
  - **מחיר מכירה ורווח**: הזנת מחיר → רווח ומרווח; או מרווח יעד → מחיר מומלץ.
- קטגוריות (אמוג'י/צבע) + אייקון למרכיב.
- **ייבוא מאקסל** (אותו פורמט של Maites).
- **ייצוא PDF / Word** — מתכון בודד, ספר מתכונים, דף תמחיר.

## מוצרים
- רשימת מוצרים; לכל מוצר: שם, ברקוד, גודל אריזה + יחידה, תמונה.
- **מחירים מהרשתות**: שופרסל, רמי לוי, ויקטורי, יוחננוף, אושר עד, **קרפור** (עוד בעתיד).
  - משיכה **יומית** ב-GitHub Actions מקבצי חוק שקיפות המחירים → רק מוצרים (ברקודים) שברשימה → Firestore.
  - **בחירת עיר** → מחירים מסודרים מהזול ליקר, לפי רשת/סניף.
  - **עריכה ידנית** של מחיר (גובר על המשוך, מסומן "ידני").
- **קטגוריות** (אפייה, חלב וביצים, שוקולד, מזווה) + **חיפוש** (שם, מותג, ברקוד). גם במתכונים: קטגוריות + חיפוש לפי שם/מרכיב.
- **מועדפים**.
- **סריקת ברקוד** (ML Kit) להוספת מוצר.
- **רשימת קניות ממתכונים**: בחירת מתכונים + כמויות → רשימה מאוחדת לפי מוצר + הרשת הזולה לסל כולו.

## התראות (2026-11-16)
- **ירידת מחיר**: למוצר (בעיקר מועדפים) — "מתחת ל-₪X" או "ירידה של X%", בעיר הנבחרת / ברשת מסוימת. נבדק אחרי המשיכה היומית, נשלח ב-FCM.
- **מיקום**:
  - **כניסה לסופר** (גדר סביב סניפים של הרשתות שנבחרו) → "יש לך רשימת קניות" / "3 מוצרים מהמועדפים זולים כאן היום".
  - **לפי עיר**: כניסה לעיר → מחירים והתראות מתחלפים לעיר הזו (או הצעה להחליף).
  - הגדרות: אילו רשתות/סניפים, רדיוס, הגבלת ימים ושעות, פעם/בכל פעם. לקחים מ-noted / HEB-CALENDAR-2026 (רקע, אתחול, "לאפשר תמיד").
- **זמנים**: תזכורת קבועה (למשל "סיכום מחירים שבועי ביום חמישי 18:00"), תזכורת לרשימת קניות, שעות שקטות.
- מסך הגדרות התראות אחד, מקובץ: מחירים · מיקום · זמנים.
